# Java DSA Problem Solving 🚀

Welcome to my **Data Structures and Algorithms (DSA) Problem Solving** repository! This repository contains my Java solutions to DSA problems and serves as a record of my learning, practice, and problem-solving journey.

## 📚 Topics Covered

The repository is organized into folders based on DSA concepts:

- **Basics** — Java programming fundamentals and basic problem solving

- **Strings** — String manipulation and related problems

- **Recursion** — Recursive problem-solving techniques

- **Matrix** — Two-dimensional arrays and matrix problems
- **OOPs** — Object-oriented programming concepts in Java

## ▶️ How to Run the Programs

### 1. Install Java

Install a JDK on your system and verify the installation:

```bash
java -version
javac -version
```

### 2. Clone the repository

```bash
git clone https://github.com/amarprakash1234/Java-DSA-ProblemSolving.git
```

### 3. Navigate to the repository

```bash
cd Java-DSA-ProblemSolving
```

### 4. Compile and run a Java program

Navigate to the folder containing the Java file, then run:

```bash
javac YourFileName.java
java YourFileName
```

Replace `YourFileName` with the actual Java filename and class name. If a program uses a package declaration, compile and run it according to that package structure.
